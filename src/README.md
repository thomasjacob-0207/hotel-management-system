# Hotel Management System

A Java Swing desktop application for managing hotel rooms and bookings, using MySQL and JDBC.

## Features
- Admin and Staff login
- Book rooms
- View bookings
- Admin management options

## Technologies Used
- Java Swing
- MySQL
- JDBC

## How to Run
1. Install Java JDK and MySQL.
2. Run `database/hotel_db.sql` in MySQL to create the database.
3. Add MySQL Connector/J to the Java project.
4. Update the MySQL username and password in `src/hotelapp/DBConnection.java`.
5. Run `src/hotelapp/LoginPage.java`.

## Login Details
- Admin: admin / admin123
- Staff: staff / staff123
